# دليل المصدر والبناء

## ما نُشر

نُشرت ملفات ترجمة العربية والمرجع والسياق والمفاتيح، والمسرد ودليل الأسلوب، وسجلات المراجعة، والشيفرة الخاصة بالاستخراج والتحقق والبناء والتركيب، ومصادر إصلاح الخط والعرض، واختبارات الأدوات وتقارير التحليل النصية. حزمة اللاعب الجاهزة تبقى في صفحة الإصدار ومجلد `downloads`.

لم تُنشر أصول اللعبة المستخرجة أو مفاتيحها أو تفريغات الانهيار أو ملفات الحفظ أو بيانات حساب المشغّل أو ملفات الأدوات التنفيذية التابعة للغير. احتُفظ بالأرشيف الفني الأصلي، وقد يصف تجربة قديمة فشلت أو نسخة سابقة؛ المرجع الحالي للاعب هو الصفحة الرئيسية وصفحة الإصدار.

## إعداد نسخة محلية

البيئة التي استُخدمت لأدوات النصوص: بايثون **٣٫١٢٫١٠** على ويندوز. استنسخ المستودع ثم ثبّت متطلبات أدوات النصوص:

</div>

```powershell
git clone https://github.com/exelight7/Dispatch_AR.git
cd Dispatch_AR
python -m pip install -r requirements.txt
```

## فحوص لا تحتاج إلى اللعبة

</div>

```powershell
python -X utf8 scripts/localization.py selftest
python -X utf8 scripts/validate_translation.py --selftest
python -X utf8 scripts/install.py --selftest
python -X utf8 scripts/validate_translation.py
python -X utf8 tools/translation_qa/qa.py
```

<div dir="rtl">

الفحص الذاتي للمثبت يستخدم ملفات اختبار وهمية، ولا يركّب التعريب في اللعبة. الملاحظات الآلية تحتاج إلى مراجعة بشرية، ولا تعني جميعها أخطاء ترجمة.

## بناء حزمة النصوص

١. تحتاج إلى نسخة اللعبة المدعومة محليًا. نزّل أداة [repak بالإصدار المستخدم ٠٫٢٫٣](https://github.com/trumank/repak/releases/tag/v0.2.3)، وضع ملفها التنفيذي في المسار المتوقع `tools/repak-v0.2.3/repak.exe`. راجع مصدر الأداة وترخيصها عند تنزيلها.

٢. أنشئ مجلدات العمل المحلية إن لم تكن موجودة:

</div>

```powershell
New-Item -ItemType Directory -Force builds, backups, extracted | Out-Null
```

<div dir="rtl">

٣. اقرأ [وصف الاستخراج الفني](EXTRACTION.md) قبل تشغيله. تحدد المسارات التالية مجلد اللعبة لديك؛ غيّر المثال ليتوافق مع مكتبتك. هذه الأدوات تقرأ الملفات وتكتب مخرجاتها محليًا، ولا تشغّل اللعبة:

</div>

```powershell
python -X utf8 scripts/investigate.py extract --game-root "D:\SteamLibrary\steamapps\common\Dispatch"
```

<div dir="rtl">

يجب أن تبقى موارد النصوص الأصلية في المسارات التي تسجلها قيمة `source_file` داخل `translation/source`. يحتفظ المستودع بالترجمات والمفاتيح؛ لا يعيد توزيع ملفات الموارد الأصلية. لا تشغّل تصديرًا يعيد إنشاء بيانات الترجمة على عملك قبل الاحتفاظ بنسخة منه.

٤. بعد توافر الموارد الأصلية والأداة، ابنِ حزمة النصوص:

</div>

```powershell
python -X utf8 scripts/build.py
```

<div dir="rtl">

ينتج البناء حزمة نصوص فقط داخل `builds/arabic_texts_experimental` وملفًا مضغوطًا خاصًا بها. يتحقق من الوسوم والمتغيرات والشرائح، ويبني حزمًا متطابقة ثم يعيد قراءتها للتحقق من كل ملف. هذا لا يعيد بناء حزمتي الخط والعرض تلقائيًا، ولا يثبت نجاح الرسم داخل اللعبة.

## مصادر الخط وعرض العربية

المولّدات مكتوبة بلغة سي شارب في `tools/asset_inspector`، وتستهدف بيئة ‎.NET 8 وتعتمد على `UAssetAPI` بالإصدار المثبت في ملف المشروع. بناء الأداة:

</div>

```powershell
dotnet restore tools/asset_inspector/asset_inspector.csproj
dotnet build tools/asset_inspector/asset_inspector.csproj -c Release --no-restore
```

<div dir="rtl">

وصفات المراحل ومدخلاتها واختباراتها موثقة في [دليل الأداة الفني](../tools/asset_inspector/README.md). مصادر البناء الأحدث موجودة في `tools/r8b_023`، ومصادر إصلاح الخط في `tools/font_017`، واختبار محرك ٤٫٢٧ في `tools/ue427_stock_reveal_test`.

بعض التجارب تعتمد على ملفات أصول أو لقطات مراحل مجمدة غير موزعة، وعلى مكتبات تحليل اختيارية أو نسخة محلية من المحرك. يلزم تجهيز تلك المدخلات من نسختك المحلية وفق وصف المرحلة؛ لا ندّعي أن أرشيف المصادر وحده يعيد إنتاج كل التجارب بأمر واحد. أزيلت مسارات جهاز المؤلف الشخصية؛ المسارات المحلية النموذجية في الأدوات التاريخية قد تحتاج إلى تعديل.

المكتبات الاختيارية المستخدمة في مسارات التحليل تشمل أدوات الصور وفك القوام والتعرف البصري والتحليل الثنائي وتشكيل النصوص؛ ملفات الاستيراد في كل أداة تبين احتياجاتها. ملف المتطلبات الأساسي لا يثبت جميع مكتبات كل تجربة.
