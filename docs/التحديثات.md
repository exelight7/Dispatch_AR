# سجل التحديثات

## النسخة التجريبية الأولى — ٢٨ أكتوبر ٢٠٢٦

- نشر حزمة واحدة تضم النصوص والخط ودعم عرض العربية.
- حزمة النصوص تشمل ١٢٬٩٧٣ مدخلًا عبر الحلقات الثماني والموارد المشتركة وموارد أخرى محددة.
- اكتملت أحدث قراءة لجميع سجلات الحوار والاختيارات والتسجيلات الصوتية البالغ عددها ٨٬٣٦٩ سجلًا، وأضيفت ٥٢ معالجة للإملاء والنحو والصياغة والمعنى.
- أبقيت نصوص الإعدادات وأسماء مفاتيح التحكم الـ٤٦٥ بالإنجليزية، وفق تفضيل المشروع الحالي.
- نجحت فحوص بنية النصوص والوسوم والمتغيرات وفواصل التوقيت، مع صفر أخطاء بنيوية.
- نجحت تسعة فحوص للحزمة، وتطابقت بصمة حزمة النصوص المركبة مع البناء.

### حدود هذه النسخة

الإصدار تجريبي. لم تُشغّل اللعبة بعد أحدث مراجعة نصية، ولا يوجد قبول بصري شامل لحركة عرض العربية الحالية. بقيت بعض العبارات المحتاجة إلى سياق دون تغيير بدل فرض تفسير غير مؤكد. التفاصيل في [تقرير المراجعة](مراجعة_الحوارات.md).
